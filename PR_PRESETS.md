# feat: пресеты, игнор объекта слежки в зоне взаимодействия, `me` → свой ID

Три независимые возможности.

## 1. Система пресетов настроек
Пресет — это полный профиль настроек скрипта (значения функций + горячие
клавиши + список чекера игроков), сохраняемый в отдельный человекочитаемый
JSON (`gadmin/configuration/presets.json`) и применяемый одной кнопкой.
Встроен **секцией во фрейм «Настройки»**.

- Редактор выглядит как экран «Настройки»: тумблеры/слайдеры значений; подсекции,
  «Горячие клавиши» и «Чекер игроков» открываются в детальном попапе.
- **Полное редактирование в пресете**: хоткеи (с попапом условий активации —
  «в слежке / на /alogin / …») и список чекера правятся независимо от живых
  настроек; применяются только по кнопке «Применить».
- Применение по настраиваемой горячей клавише; активный пресет подсвечен
  в списке + бейдж назначенной клавиши.
- Пароли (аккаунт / alogin) в пресет не попадают.

Затронуты общие виджеты:
- `submenu` — хуки подсветки/оверлея/резерва текста записи, безопасное (без
  инвалидации итерации) удаление записи с коррекцией индексов, гибкая раскладка
  меню↔контент.
- `button` — инсет текста по `FramePadding` (центрированные кнопки не меняются,
  лево/право-выровненные больше не прилипают к краю).
- `hotkey` — опциональное внешнее хранилище бинда (правка хоткеев пресета без
  изменения живых).

## 2. Отключение наведения на объект слежки
Новая опция `windows.interaction_area.ignore_spectated_target` (вкл. по
умолчанию). Когда включена, круговая панель взаимодействия не наводится на
игрока/транспорт, за которым ведётся слежка. Тогл — клавишей `0` в зоне;
настройка в подсекции «Круговая панель».

## 3. Замена `me` на собственный ID
`me_to_id`: первый аргумент команды `me` заменяется серверным ID игрока
(`/aheal me` → `/aheal 14`). Только первый аргумент — `/me` и слова `me`
в тексте сообщений не трогаются; работает после `short_commands` (раскрытые
алиасы тоже учитываются). Опция `misc.me_to_id` (вкл. по умолчанию), раздел
«Прочее».

## Сборка / проверка
Сборка MinGW GCC (без ошибок), проверено в игре на Gambit-RP.
